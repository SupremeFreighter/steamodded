## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Custom Jokers** | Add entirely new joker cards with unique scoring effects and synergies |
| **New Decks** | Create custom starting decks with modified rules and special properties |
| **Game API** | Rich Lua API for hooking into scoring, shop generation, and game events |
| **Community Mods** | A growing library of community-created content ready to install |
